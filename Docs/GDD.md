# Labyrinthino — геймдизайн-документ

Оригинальный ГДД (Приложение 5 к КЗ) в материалах не приложен, поэтому значения ниже выбраны разработчиком
и согласованы с критериями оценки. Все числа живут в `Assets/Project/Scripts/Data/MiniGameCatalog.cs`.

**Жанр:** сборник казуальных головоломок-лабиринтов. **Платформа:** планшет, портретная ориентация.
**Аудитория:** 6+, семейная игра. **Движок:** Unity 6 (URP, uGUI).

## Экраны
Загрузка → Карта «Мини-игры» (главный экран) → Окно «Мини-игра» (карточка, описание, уровни) → игра → Победа / Поражение. Настройки — с карты.

- **Экран загрузки:** анимированный логотип, вращающийся индикатор, полоса прогресса с названием этапа и процентами.
- **Карта:** 4 карточки покачиваются; вид зависит от прогресса (новая — приглушена, начатая — цветная с полосой «Уровень N из M», пройденная — золотая рамка и галочка).
- **Окно «Мини-игра»:** описание, чипы уровней (пройден / текущий / закрыт), кнопка «Играть» / «Продолжить» / «Пройдена» (повтор невозможен).
- **Настройки:** ползунки музыки и звуков (сохраняются), сброс прогресса с подтверждением.
- **Победа:** медаль, лучи, конфетти, кнопки «Продолжить» (следующая непройденная игра) и «На главную».
- **Поражение:** тучка, дождь, кнопки «Попробовать ещё раз» (текущий уровень) и «На главную».

## Мини-игры
| Игра | Уровни | Правила |
|---|---|---|
| Викторина | 5 слов: ДОМ, РЫБА, ГРИБ, ЛОДКА, СОЛНЦЕ | Картинка скрыта маской 4×4, в центре открыто 25 %. Таймер 60 с, 3 попытки. Кнопки с буквами: все буквы слова + 2–3 лишние, порядок случайный. Буквы попадают в поле ввода по порядку; «Стереть» удаляет последнюю, «Отправить» проверяет. Верно: анимация раскрытия, надпись «Верно! Это — СЛОВО», следующий уровень (после последнего — Победа). Неверно: звук ошибки, сообщение «Неверно! Осталось попыток: N», открывается +25 % (50 → 75 → 100 %). После 3-й ошибки или 0 с картинка открывается полностью, надпись «Попытки закончились. Это — СЛОВО», далее следующий уровень (после последнего — экран «Мини-игры»). |
| Найди путь | 3 сетки: 4×4, 5×5, 6×6 | Старт (S), финиш (F), препятствия (#), пустые клетки. При запуске 3 секунды показывается кратчайший путь. Игрок касается соседних клеток по очереди (по горизонтали/вертикали); касание соседней клетки-препятствия — звук ошибки, выход за сетку игнорируется, касание предыдущей клетки откатывает шаг. «Сбросить» возвращает на старт. Финиш: анимация волной, «Путь найден!», следующий уровень / Победа. |
| Лугомания | 4×4 (6 коричневых, 9 ходов, 30 с), 5×5 (12, 16, 40 с), 6×6 (20, 26, 50 с) | Поле со смесью коричневых и зелёных клеток (раскладка по зерну). Касание коричневой делает её зелёной, касание зелёной тратит ход и игнорируется. Все зелёные → следующий уровень / Победа. Ходы кончились или 0 с → Поражение, можно перезапустить. |
| Соединяй точки | 4×4 (40 с), 5×5 (50 с), 6×6 (60 с) | Несколько стартовых точек (подсвечены и пульсируют), обязательные точки (звёзды), точка назначения (домик), препятствия. Маршрут начинается только со стартовой точки, строится касаниями соседних клеток, рисуется линией; нельзя пройти дважды по клетке, сквозь препятствие и за поле. Достижение домика «защёлкивает» маршрут: если посещены все обязательные точки — следующий уровень / Победа, иначе маршрут сбрасывается с сообщением. 0 с → Поражение. |

## Сохранение данных
`persistentDataPath/labyrinthino_save.json` (+ резервная копия `.bak`, запись через временный файл): громкость музыки и звуков; для каждой игры число пройденных уровней; снимок незавершённого уровня (оставшееся время, попытки/ходы, поле Лугомании). Пройденная игра повторно недоступна.

## Звук
Фоновая музыка (петля), звуки: нажатие кнопок, касание клетки, шаг, верно, ошибка, победа, поражение. Громкость музыки и звуков регулируется отдельно.

## Адаптивность
Canvas Scaler: Scale With Screen Size 1080×1920, режим Expand; содержимое окон занимает область 1080×1920 по центру, фон растягивается. Работает на планшетах и телефонах в портрете.

# Выжимка требований (КЗ «Разработчик мобильных игр», СПб 2026)

Игра «Labyrinthino» для планшета (портрет). Модули: А арт/проект (логотип, постер, окна Победа/Поражение), Б UI (Canvas, uGUI, нестандартный шрифт, адаптивность), В механики (4 мини-игры + 4 юнит-теста), Г сохранение, Д билд, Е питч.

Баллы: А 6, Б 13, В 51.5, Г 8.25, Д 5.5, Е 15.75. Программирование: summary с `param` у всех классов и методов, без закомментированного кода, MS-нейминг, скрипты по подпапкам. Ресурсы названы по-английски, папки структурированы. Аудио: громкость музыки и звуков регулируется и сохраняется.

Юнит-тесты (Assets/Project/Tests/EditMode): Викторина «Стереть», Найди путь «Сбросить», Лугомания начальное состояние, Соединяй точки старт только со стартовой точки.
